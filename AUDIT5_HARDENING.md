## КЛАСТЕРЫ НАХОДОК (сходимость ≥2 независимых лейнов = сильный сигнал)

### Кластер 1 · РЕАЛЬНАЯ СРЕДА ≠ ЗЕЛЁНЫЙ СВОД (антарая: бхранти-даршана) — деплой-блокеры
Зелёные 712u/405e меряют путь, которого в проде нет. Верифицировано оркестратором.
- **C1 · base-path /api/v1 ≠ /v1** (frontend+alpha-analyst+оркестратор). `main.ts` без setGlobalPrefix →
  маршруты `/v1/...`; контракты и Caddy `handle /api/*` без strip → все 124 операции 404 через Caddy;
  живёт только `/health/*`. 238 e2e бьют supertest'ом мимо Caddy → зелено маскирует. **Верифицировано.**
- **Ф-1 · H4-петля мертва на свежей установке** (devops+оркестратор). Шаблон saved_search_matched
  в миграции 0037, НЕ зеркалирован в database_schema.sql (0 vs 3 у transfer_initiated). Свежий деплой
  (schema+seed) → 22 шаблона из 24 → notification-writer warn+return false → петля молча мертва.
  Доказано контролем: 13 failed на CI-базе vs 23/23 на replay-базе. **Верифицировано (0 вхождений в каноне).**
- **Б1 · throttler — один ковш на всю платформу** (backend+security). trust proxy не выставлен + Caddy
  единственный вход → 100 req/60с = 1,67 req/s на всех; регистрация 5/15мин на всех → 6-й юзер за 15 мин
  = 429. Ломается в день выхода на 1000 DAU (пик 1,74 req/s). Agent-обмен 60/ч тоже общий.
- **Б2 · H4 пустой заголовок для en-объявлений** (backend+active-user+ui). ru-fallback структурно не
  срабатывает: consumer схлопывает отсутствующую локаль в '', writer `??` на '' не откатывается.
  141/3325 юзеров — 'en'. Юнит зелен, т.к. кормит обе локали (ось 13 не ловит мутацию).

### Кластер 2 · МАШИНА РАБОТАЕТ, СООБЩЕНИЕ МОЛЧИТ (ось 2 красная) — 5 лейнов
За июль исправлена машина и не тронут слой сообщений. Продукт умеет уведомлять, не умеет СКАЗАТЬ.
- Уведомления несут UUID вместо клички/названия: `Объявление «7f3a…» отклонено. Причина: prohibited_species.`
  (ui: 42/71 строк дефектны, 22/22 EMAIL-шаблона; active-user A-1/A-2; ux B1/B2; psychologist P-1/P-2).
  Тёплый текст (moderation_reasons.description_localized, notes) ЛЕЖИТ рядом, в канал не идёт.
- Покупатель не видит животное: ListingView 0 полей о животном, animals→404 гостю (active-user A-1 BLOCKER).
- Настройки контактов write-only: PATCH /me принимает, GET /me не отдаёт (ux C1; active-user).
- **notification_logs.status жёстко 'SENT'** — журнал лжёт (growth+оркестратор, верифицировано); отправителя
  (SMS/email к консьюмерам) нет, читателя (фронта) нет → петля оборвана в 3 местах (growth).
- Класс: бхранти-даршана (под капотом верно → до глаза не доехало) + композиционный гейт vs обещание дизайна.

### Кластер 3 · АГЕНТ-ВЛАСТЬ НЕ ПРИНУЖДАЕТСЯ (NO-GO, блок [NS] North-Star) — security живьём
- **P0-1** PoliciesGuard fail-OPEN (`policies.guard.ts:39`) → scope AGENT на 1 из 83 маршрутов; ADR-0037
  «роль недостаточна для AGENT» на 100% неверна (живьём: агент scope=undefined → queue/reasons 200).
- **P0-2** AGENT-ADMIN флипает свой мастер-гейт (feature-toggle проверяет role, не principalType, живьём).
- **P0-3** человеческие сессионные пути (refresh/verifyPhone/oauth/recovery) чеканят AGENT-токен без scope.
- **P1-1** секрет агента в Redis 24ч (IdempotencyInterceptor кэширует тело) — опровергает «never persisted».
- **P1-2** обмен не смотрит user.status (SUSPENDED агент получает токен). Не живая эксплуатация (гейт OFF,
  агентов в проде нет), но зажигать agent_service_auth нельзя до 5 фиксов (1–3 архитектурные → ADR-0037).

### Кластер 4 · ГЕЙТЫ НЕ ЗАЩИЩАЮТ ТО, ЧТО ДЕКЛАРИРУЮТ (антарая: бхранти-даршана) — reviewer-qa
Прямое воплощение закона «зелёное ≠ проверено» в собственных замках ZooLink.
- **Р-9** drift-гейт односторонен: обе дорожки стартуют с database_schema.sql → мутация в КАНОН проходит
  зелёной; миграции никогда не доказаны как самостоятельный путь. **Корень Ф-1 и confirm_expires_at-дрейфа.**
- **Р-10** БД-инвариантные e2e меряют dev-БД, не артефакты: удаление `uq_reviews_current_per_direction`
  из канона+миграции → reputation-storage.e2e 16/16 зелено (db:sync introspect-only, живая БД держит старое).
  Класс ≈40 ассертов (append-only/CHECK/UNIQUE/GENERATED). **Верифицировано: тест не пинует констрейнт по имени.**
- **Р-3** оракул существования пережил починку: AUDIT2#5 закрыл /animals/{id}, но /ownership-history и
  /transfers/{id} дают 403/404 для того же id — и это ЗАКРЕПЛЕНО тестом (transfer.service.spec.ts:555). анавастхитатва.
- **Р-11** H4-3 арифметически не способен увидеть дубликат (считает по ключу с UNIQUE ∈{0,1}); спас H4-17 (новый в c44874c).
- Р-1 три TOCTOU-замка без свидетеля; Р-2 audit_log без негатив-теста; Р-6 market-гейт пропускает Prisma-путь
  (CLAUDE.md 0037 прямо «reworded docstring avoids grep-gate»); Р-7/Р-8 backfill-гейт слеп, охват рукой.
